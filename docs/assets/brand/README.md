# ChronoStack logo

Two interlocking loops (the services of your stack, locked to one clock) with an amber arc on top (time).

| File | Use |
|---|---|
| `chronostack-logo-light.svg` / `.png` | Mark and name, for light backgrounds |
| `chronostack-logo-dark.svg` / `.png` | Mark and name, for dark backgrounds |
| `chronostack-mark-light.svg` / `-512.png` | Mark only, for light backgrounds |
| `chronostack-mark-dark.svg` / `-512.png` | Mark only, for dark backgrounds |
| `chronostack-avatar.png` | 800×800 square for GitHub, social or package avatars |

Colours: ink `#14161A` (light backgrounds) or `#F4F2EC` (dark backgrounds); amber `#F2A33A`.

In Markdown, switch with the reader's theme:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/assets/brand/chronostack-logo-dark.svg">
  <img alt="ChronoStack" src="docs/assets/brand/chronostack-logo-light.svg" width="440">
</picture>
```

The SVGs were traced from the original artwork with potrace, so the text is outlined and needs no font.
